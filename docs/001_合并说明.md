# mach-calculators 合并说明

日期：2026-07-02

## 背景

原仓库中存在两个小包：

- `packages/mach-formulas`：数控加工公式库。
- `packages/mach-calculators`：计算器 schema 和公式适配层。

二者代码量不大，且 `mach-calculators` 对 `mach-formulas` 是上层薄封装。独立发布两个 npm 包会引入额外版本同步和发布维护成本。

## 决策

合并为单个 npm 包：`@usethink/mach-calculators`。

合并后的模块边界：

- `@usethink/mach-calculators/formulas`：公式库。
- `@usethink/mach-calculators/schema`：计算器 schema。
- `@usethink/mach-calculators/adapters`：表单输入到公式输入的适配层。

## 发布策略

该包迁移到 `/Users/dingyuwang/0-X/2-node/mach-calculators`，按 `@usethink/cf-core` 的单包 npm 发布流程维护：

- `npm ci`
- `npm run type-check`
- `npm test`
- `npm run build`
- `publish-toolkit publish`
